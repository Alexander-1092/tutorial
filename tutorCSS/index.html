flexbox

Основной гайд по флексбоксу

flexbox - инструмент для гибкого распределение места между элементами.

Флекс-контейнер - элемент, к которому применяется свойство display: flex.

Флекс-элемент - элемент, вложенный во флекс-контейнер.

Основная ось - основная направляющая флекс-контейнера, вдоль которой располагаются флекс-элементы (горизонтальная).

Поперечная - ось, идущая перпендикулярно основной(вертикальная).

Для создания флекс-контейнера используем:

display: flex; - создаем флекс контейнер, все его элементы начинают подчиняться свойствам флексбокса. Снаружи такой контейнер ведет себя как блочный элемент.

display: inline-flex; - поведение внутри такое же как и у обычного display: flex, но снаружи ведет себя как инлайновый элемент.

flex-direction

Свойство управления направлением основной и поперечной осей.

row - контент по основной оси распологается слева направо, по поперечной сверху вниз

row-reverse - контент по основной оси распологается справа налево, по поперечной сверху вниз

column - контент по основной оси идет сверху вниз(вертикально),по поперечной горизонтально и слева направа

column-reverse - контент по основной оси идет снизу вверх(вертикально),по поперечной горизонтально и слева направа

.parent{
    display: flex;
    flex-direction: row;

flex-wrap

nowrap - состояние по умолчанию. Весь контент флекс-контейнера помещается в один ряд без переноса.

wrap - элементы котнейнера переносятся в новый ряд, если происходит переполнение.

wrap-reverse - элементы переносятся, но распологаются снизу верх.

flex-flow

flex-flow - это сокращение двух свойств flex-direction и flex-wrap. Вначале указывается значение свойства flex-direction, а затем и flex-wrap

  display: flex;
  flex-flow: column wrap;

justify-content

Свойство позволяет выравнивать флекс-элементы внутри флекс-контейнера по основной оси.

start - элементы прижимаются к тому краю, откуда начинается чтение на том языке, на котором отображается сайт.

end - элементы прижимаются к краю, противоположному началу направления чтения на языке.

flex-start - элементы прижимаются к краю, от которого начинается основная ось.

flex-end - элементы прижимаются к краю, у которого основная ось заканчивается.

left - элементы прижмутся к левому краю родителя.

right - элементы прижмутся к правому краю родителя.

flex-start/left и flex-end/right обычно дают одинаковый результат, но работают по-разному в специфических ситуациях. flex-start и flex-end учитывают значения flex-direction, например при flex-start в сочетании row-reverse, контент будет прижат к правому краю контейнера, тогда как при значении left строго к левому.

center - элементы выстраиваются по центру родителя.

space-between - крайние элементы прижимаются к краям родителя, оставшиеся выстраиваются внутри контейнера равномерно, так, чтобы между ними были одинаковые отступы.

space-around - свободное пространство делится поровну между элементами и по половине от этой доли размещается по бокам от каждого элемента. Таким образом, между соседними элементами будет равное расстояние, а снаружи крайних элементов — по половине этого расстояния.

space-evenly - свободное место будет распределено так, чтобы расстояние между любыми двумя элементами было одинаковым и расстояние от крайних элементов до края было таким же.

.parent{
    display: flex;
    justify-content: start;
}

align-items

Свойство выравнивания элементов внутри контейнера по поперечной оси.

stretch - элементы растягиваются вдоль поперечной оси, если не заданна высота элементов (по умолчанию).

flex-start/start - элементы выстраиваются у начала поперечной оси / второе значение учитывает направление текста в браузере.

flex-end/end - элементы выстраиваются у конца поперечной оси/ второе значение учитывает направление текста в браузере.

center - элементы выстраиваются по центру поперечной оси.

baseline - элементы выравниваются по базовой линии текста. «Базовая линия» — baseline — воображаемая линия, проходящая по нижнему краю знаков шрифт.

align-content

Свойство распределяет свободное пространство по поперечной оси между рядами флекс-элементов. Работает только при flex-wrap: wrap или wrap-reverse. Не работает если все элементы в одной строке. Действует на группы строк, а не на отдельные элементы, и распределяет свободное пространство между этими элементами.

stretch - ряды растягиваются одинаково, так, чтобы занять всё доступное пространство родителя (по умолчанию).

flex-start/start -все ряды располагаются у начала поперечной оси.

flex-end/end -все ряды располагаются у конца поперечной оси.

center - ряды выравниваются по центру родителя.

space-between - первый ряд прижимается к началу поперечной оси, последний — к концу поперечной оси, а остальные располагаются так, чтобы свободное пространство было поделено на отступы между ними равномерно.

space-around - отступы у каждого ряда равнозначны отступам у любого другого ряда.

space-evenly - отступы между рядами и от краёв родителя одинаковые.

order

Cвойства order помогает менять порядок отображения флекс-элементов внутри флекс-контейнера.

В качестве значения order принимает как отрицательные, так и положительные числа, по умолчанию стоит ноль. Чем меньше значение, тем раньше будет отображаться элемент.

Если значение order одинаковое у пары или нескольких элементов, то тогда они будут распологаться согласно порядку в котором идут в HTML.

1

3

    display: flex;
    .child 1{order: 0;}
    .child 2{order: 0;}
    .child 3{order: 0;}
    .child 4{order: 0;}
}

flex-grow

Это свойство указывает, может ли вырастать флекс-элемент при наличии свободного места, и насколько. По умолчанию значение равно 0. Значением может быть любое положительное целое число.

Принцип работы: делится только оставшееся место между элементами. Например наш контейнер 600px, есть 3 элемента по 100px, итого свободного места остаётся 300px. Именно эти 300px будут распределяться между элементами взависимости от значения flex-grow.

Если у всех элементов стоит flex-grow: 1, то оставшееся место будет разделенно поровну между элементами, то есть по 100px (элементы станут по 200px каждый). Если только у одного элемента значение flex-grow: 1, а у остальных 0, то всё свободное пространство займет элемент с единицей. В случае если у одного элемента стоит 2, а у других 1, то первый элемент займет дополнительные 150px (250px в итоге), а два других по 75px (станут по 175px)

Когда размер элемента не указан, то за минимальный размер будет браться содержание его контента.

1
2
3
.parent{
    display: flex;
    .child 1{flex-grow: 0}
    .child 2{flex-grow: 0}
    .child 3{flex-grow: 0}
}

flex-shrink

Противоположно свойству flex-grow - уменьшает элемент. По умолчанию значение равно 1. Размер уменьшения высчитывается от переполнения контейнера, на сколько выходит за рамки, и на данное число уменьшает элемнт/элементы взависимости от значения.

Принцип работы: рассмотрим контейнер высотой 200px, содержащий три элемента по 100px каждый. Общая высота элементов составляет 300px, что создает переполнение в 100px. Именно эта недостающая площадь будет распределена между элементами пропорционально их коэффициентам сжатия (flex-shrink). Например:

Если у двух элементов flex-shrink: 0, а у третьего flex-shrink: 1 Два элемента сохраняют свою высоту (100px), а третий сжимается до высоты своего содержимого, компенсируя всё переполнение.

Если у всех элементов flex-shrink: 1 Переполнение в 100px распределяется равномерно: каждый элемент теряет примерно по 34px, уменьшаясь до ~66px.

Если у двух элементов flex-shrink: 1, а у третьего flex-shrink: 2, то сжатие происходит пропорционально значениям: Элементы с коэффициентом 1 теряют по 25px (уменьшаются до 75px) Элемент с коэффициентом 2 теряет 50px (уменьшается до 50px)

1
2
3
.parent{
    display: flex;
    flex-direction: column;
    height: 400px;
    overflow: hidden;
    .child 1{flex-shrink: 1; height: 200px;}
    .child 2{flex-shrink: 1; height: 200px;}
    .child 3{flex-shrink: 1; height: 200px;}
}

flex-basis

Свойство flex-basis указывает на предпочтительный размер элемента. Взависимости от направляние главной оси флекс-контейнера задает ширину или высоту. По своему действию имеет свходство с свойствами width и height, но в отличие от них при работе с flex-shrink\flex-grow может изменить указанный размер.

Flex - cвойство-шорткат (сокращенная запись нескольких свойств) - flex-grow, flex-shrink и flex-basis. Значение по умолчанию: 0 1 auto, что расшифровывается как flex-grow: 0, flex-shrink: 1, flex-basis: auto.

gap

С помощью этого свойства можно с лёгкостью задавать отступы между строками и столбцами. Является краткой записью свойств row-gap и column-gap.

Может иметь одно или два значения. Если указано только одно, то column-gap автоматически равен row-gap. Если указаны два значения, то первое будет задавать отступы между рядами (row-gap), а второе — между колонками (column-gap).

Значения можно указывать в любых доступных единицах измерения, включая проценты. Допускается использование функции calc()

grid

Гайд по гриду

Grid — это инструмент для создания сеток на веб-странице, и позволяет одновременно управлять колонками и строками.

Грид-контейнер - родительский элемент, к которому применяется свойство display: grid.

Грид-элемент - дочерний элемент, прямой потомок грид-контейнера. Подчиняется правилам раскладки гридов.

Грид-линия - это разделительная черта между колонками и строками в грид-сетке. Может быть как вертикальной (грид-линия колонки), так и горизонтальной (грид-линия ряда). Располагается по обе стороны от колонки или ряда.

Грид-ячейка - пространство между соседними грид-линиями. Единица грид-сетки.

grid-template-columns|grid-template-rows

grid-template-columns - cвойства, задающие размеры (ширину) и количество колонок.

grid-template-rows - свойства, задающие размеры (высота) и количество строк.

Для того чтобы задать количество колонок/строк необходимо в строку прописать их размер, например grid-template-rows: 50px 50px 50%;

Можно использовать разные единицы: px, %, fr (доли), auto, minmax(), repeat()

auto - значение определяется по содержанию контента

minmax() - это функция, которая задает минимальный и максимальный размер. Ячейка станет вести себя как резиновая, не сожмется меньше минимального значения, и не растенется больше максимального.

fr - единица измерения свободного пространства в грид-контейнере, работает по такому же принципу как flex-grow в флекс-контейнере, то есть пропорционально распределяет свободное пространство, с учетом всех фиксированных размеров и отступов.

repeat() - это функция, которая позволяет повторить кроичество и размер колонок или строк. Вначале пишем количество, зачем размер, например repeat(2, 20px) repeat(2, 1fr) - создадим 4 колонки, две ячейки шириной в 20px и две ячейки шириной в 1fr

auto-fill - это свойство которое используется только внутри repeat(), и автоматически рассчитывает количество колонок внутри грид-контейнера. Для расчета auto-fill требуется указать размер колонки, например grid-template-columns: repeat(auto-fill, 100px). В теории полезен если используются гибкие единицы fr совместно с minmax (если использовать просто fr без minmax, то работать не будет). Механизм работы: разбивает всё пространство контейнера на равные колонки. Колонки с элементами не растягиваются. Остается пространство.
Сомнительное свойство, не совсем понятно где и как его использовать.

auto-fit - действует также как и auto-fill, отличие в том что оно растягивает колонки по ширине контейнера. Например, grid-template-columns:repeat(auto-fit, minmax(20px, 1fr)) нет пустых колонок, колонки растянуты по ширине, тогда как при auto-fill колонки будут занимать 20px, и образуются пустые колонки в сетке.

Грид линия это структурная основа грид-контейнера, они делят контейнер на строки и колонки. Грид-линий всегда на одну больше чем колонок/строк. Три колонки - 4 вертикальных линий, две строки - 3 горизонтальных линии.

Для лучшей поддерживаемости кода, данным линиям можно давать имена. Имена записываются в квадратных скобках перед указанием размера колонки (от линии к линии). 

  grid-template-columns:
    [sidebar] 250px
    [content] 1fr
    [aside] 200px;
    [end];

Имя линий похожи на имена классов, их может быть нескольк у одной линии, также их можно будет использовать при работе с элементами сетки (grid-colum, grid-row).

grid-column, grid-row

grid-column - шорткат свойств grid-column-start, grid-column-end

grid-row - шорткат свойств grid-row-start, grid-row-end

Данные свойства определяют положение элемента внутри грид-сетки при помощи указания на конкретные направляющие линии.

Указать положение линии можно с помощью:

  • Названия линии или его номера;
  • span число;
  • span имя;
  • auto - значение по умолчанию.

grid-column-start - указывает с какой линии должен начинаться элемент колонки

grid-column-end - указывает на какой линии должен закончиться элемент колонки.

grid-row-start - указывает на какой линии должен начаться элемент строки.

grid-row-end - указывает на какой линии должен закончиться элемент строки.

Например, если в грид-контейнере с 3 колонками, первому элемнету зададим grid-column-start: 1 и grid-column-end: 4, то он зайймет всю первую строку, то есть с первой линии по последнюю.

grid-column: grid-column-start / grid-column-end - для сокращенной записи, вначале указываем линию начала, слэш, линию конца. Аналогично и для grid-row.

По номеру: grid-column: 1 / 4

По имени:

.parent{
    grid-template-columns:
    [start] 1fr
    [line2] 1fr
    [line3] 1fr
    [end];
    grid-template-rows:
    [start-row] 1fr
    [line2-row] 1fr
    [line3-row] 1fr
    [end-row];
    .child 1 {
        grid-column: start / end;
    }
    }

grid-colum: span 3; - свойство span растягивает элемент на n ячеек.

Можно комбинировать с указаниями с какой линии начать/закончить, например, grid-colum: 2 / span 3;. Вместо числового обозначения линии можно также использовать их имена, grid-colum: line2 / span 3;

grid-auto-columns, grid-auto-rows

Существуют явные и неявные колонки/строки. Явные это те колонки/строки, размер которых мы прописываем в grid-template-columns/grid-template-rows, а не явные которые создаются автоматически если элементу родителя задают расположение через grid-column/grid-row на несуществующих линиях или ячейках.

grid-auto-columns/grid-auto-rows - указывает какого размера должны быть неявные колонки/строки, например: 

.parent{
    display: grid;
    grid-template-columns: 100px 100px;
    grid-auto-columns: 1fr;
    .child 2{
        grid-column: 3 / 4;
    }
}

Если не указывать размер неявных колонок, то грид всё равно их создаст, в этом случае значение grid-auto-columns будет auto, то есть размер определится по контенту.

grid-auto-flow

grid-auto-flow - определяет, как будут располагаться элементы, не имеющие явной позиции, и как будут заполняться пустоты.

Свойство задает направление расположения элементов:

- row - элементы выстраиваются по строкам, слева направо (по умолчанию).

- colum - элементы выстраиваются по колонкам сверху вниз, слева направо.

Свойство задает плотность наполнения:

- dense - элементы заполняют имеющиеся пустоты, даже если они идут не по порядку.

Направление элементов

.parent{
