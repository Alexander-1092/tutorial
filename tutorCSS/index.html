flexbox

Основной гайд по флексбоксу

flexbox - инструмент для гибкого распределение места между элементами.

Флекс-контейнер - элемент, к которому применяется свойство display: flex.

Флекс-элемент - элемент, вложенный во флекс-контейнер.

Основная ось - основная направляющая флекс-контейнера, вдоль которой располагаются флекс-элементы (горизонтальная).

Поперечная - ось, идущая перпендикулярно основной(вертикальная).

Для создания флекс-контейнера используем:

display: flex; - создаем флекс контейнер, все его элементы начинают подчиняться свойствам флексбокса. Снаружи такой контейнер ведет себя как блочный элемент.

display: inline-flex; - поведение внутри такое же как и у обычного display: flex, но снаружи ведет себя как инлайновый элемент.

flex-direction

row - контент по основной оси распологается слева направо, по поперечной сверху вниз

row-reverse - контент по основной оси распологается справа налево, по поперечной сверху вниз

column - контент по основной оси идет сверху вниз(вертикально),по поперечной горизонтально и слева направа

column-reverse - контент по основной оси идет снизу вверх(вертикально),по поперечной горизонтально и слева направа

1
2
3
.parent{
    display: flex;
    flex-direction: row;
}

flex-wrap

nowrap - состояние по умолчанию. Весь контент флекс-контейнера помещается в один ряд без переноса.

wrap - элементы котнейнера переносятся в новый ряд, если происходит переполнение.

wrap-reverse - элементы переносятся, но распологаются снизу верх.

.parent{
    display: flex;
    flex-direction: row;

flex-flow

flex-flow - это сокращение двух свойств flex-direction и flex-wrap. Вначале указывается значение свойства flex-direction, а затем и flex-wrap

.container {
  display: flex;
  flex-flow: column wrap;
}

justify-content

start - элементы прижимаются к тому краю, откуда начинается чтение на том языке, на котором отображается сайт.

end - элементы прижимаются к краю, противоположному началу направления чтения на языке.

flex-start - элементы прижимаются к краю, от которого начинается основная ось.

flex-end - элементы прижимаются к краю, у которого основная ось заканчивается.

left - элементы прижмутся к левому краю родителя.

right - элементы прижмутся к правому краю родителя.

flex-start/left и flex-end/right обычно дают одинаковый результат, но работают по-разному в специфических ситуациях. flex-start и flex-end учитывают значения flex-direction, например при flex-start в сочетании row-reverse, контент будет прижат к левому краю контейнера, тогда как при значении left строго к левову.

center - элементы выстраиваются по центру родителя.

space-between - крайние элементы прижимаются к краям родителя, оставшиеся выстраиваются внутри контейнера равномерно, так, чтобы между ними были одинаковые отступы.

space-around - свободное пространство делится поровну между элементами и по половине от этой доли размещается по бокам от каждого элемента. Таким образом, между соседними элементами будет равное расстояние, а снаружи крайних элементов — по половине этого расстояния.

space-evenly - свободное место будет распределено так, чтобы расстояние между любыми двумя элементами было одинаковым и расстояние от крайних элементов до края было таким же.

.parent{
    display: flex;
    justify-content: start;
}
