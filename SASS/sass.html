SCSS

SASS это препроцессор CSS, то есть инструмент, который позволяет писать CSS с расширенным синтаксисом, после чего компилирует его в обычный CSS.

Есть две версии SASS, оригинальная, которая так и называестя SASS и современная SCSS. Разница между ними заключается в синтаксисе.

Вложенность

Структура SCSS визуально схожа с html, но вместо тегов указываются CSS селекторы.

<nav class="nav">
    <ul>
        <li>
            <a class="link"></a>
        </li>
    </ul>
</nav>

.nav{
    ul{
        li{
         .link{}
        }
    }
}

При этом вложенность не должна обязательно быть строгой, вплоть до каждого селектора.

.nav{
    margin-top: 20px;
    .link{color: red;}
}

Однако хорошей практикой считается отзеркаливанием html структуры, но это неформальное соглашение, а не правило. При этом стоит избегать избыточности.

Переменные

Чтобы создать переменную нужно использовать символ $.

$primary-color: #333;

Значение переменной может быть цвета, стеки шрифтов или любые другие значения CSS

Для того чтобы использовать созданную переменную, нам нужно указать ее название через символ $ 

button {
    color: $primary-color;
}

Оператор &

Оператор & — это ссылка на родительский селектор, то есть он копирует название родителя.

<div class="parent">
    <div class="parent__title"></div>
    <div class="parent__text"></div>
</div>

.parent {
    &__title {
        color: blue;
    }

    &__text {
        color: red;
    }
}

Миксины

Миксины - это группа CSS свойств. По своей сути эта переменная, только вместо одного значения, миксин содержит группу разных свойств.

@mixin - для создание миксина.

@include - для использования миксина.

@mixin flex-center {
    display: flex;
    justify-content: space-between;
    align-items: center;
}
container {
   @include flex-center;
}

Аргументы в миксине

В миксине можно передавать значение для свойства через аргумент. Это полезно если у вас одиноковые фрагменты кода, но разные значения свойств.

@mixin box($width, $height, $color: blue) {
  width: $width;
  height: $height;
  background-color: $color;
}

.header {
  @include box(100%, 200px, red);
}

Произвольное количество аргументов

Когда нам нужно передать большой массив значений, и затруднительно прописывать каждый аргумент.

@mixin shadows($shadows...) {
  box-shadow: $shadows;
}

.card {
  @include shadows(0 2px 5px rgba(0,0,0,0.1), 0 0 0 1px #eee);
}

@content

@content - это инструмент, который работает внутри миксина, и позволяет вставить на его место любой фрагмент когда, в том числе вложенные селекторы, медиа-запросы, даже другие миксины. Данное свойство нужно использовать тогда когда мы сами точно не знаем какие свойства будут использованны внутри.

Например:

@mixin tablet {
  @media (min-width: 768px) and (max-width: 1023px) {
    @content;  // Что тут будет? Неизвестно!
  }
}

Вариант 1

.sidebar {
  width: 300px;

  @include tablet {
    width: 100%;
    background: lightblue;
  }
}

Вариант 2

.gallery {
  display: grid;
  grid-template-columns: repeat(4, 1fr);

  @include tablet {
    grid-template-columns: repeat(2, 1fr);
    gap: 10px;
  }
}

Используются абсолютно разные свойства и значения.

@extend (наследование)

@extend -это механизм, который позволяет одному селектору получить все стили другого (или нескольких других) селекторов, без копирования кода. При этом их иерархия, где находится копируемый селектор (до или после) не важно. Но важно понимать, что в отличие от миксинов @extend не копирует код, а группирует селекторы, так чтобы они наследовали свойства.

В SCSS
 .card {
    @extend .box;
    justify-content: space-between;
}

.box {
    display: flex;
    flex-direction: column;
}

В CSS
.card {
  justify-content: center;
}

.box, .card {
  display: flex;
  flex-direction: column;
}

Placeholder-селектор %

Placeholder-селектор % - работает аналогично @extend только класс к которому применен селектор не компилируется в CSS. Получается шаблон, который существует только для наследования. Таким образом, мы избегаем "мусорных" классов. 

%box {
    display: flex;
    flex-direction: column;
}

 .card {
    @extend %box;
    justify-content: space-between;
}

Импорт в SCSS

Статья - источник

Раньше для импорта данных в SCSS применялся @import, сейчас же он считается устаревшим, и будет удален. На замену ему пришли @use и @forward

@use

@use - загружает файл (модуль) и делает его содержимое доступным в текущем файле, но в изолированном пространстве имен (переменные/миксины не будут доступны при стандартном вызове), чего не было у @import.

Использование: указываем в кавычках путь к файлу, можно без расширение, если модуль находится в папке с главным SCSS файлом, то можно просто название файла в кавычках.

При импорте обычные селекторы будут сразу применены. Для использования миксинов или переменных вначале нужно указать пространство имён, то есть имя файла, а зачем имя переменной/миксина.

module.scss

$redcolor: #e21111;

@mixin flex-wrapper {
    display: flex;
    flex-direction: column;
}

.card {
    width: 500px;
}


@use "./module";

.card {
    color: module.$redcolor;
    @include module.flex-wrapper;
}

Изменение пространства имён (as)

При импорте, мы указываем имя файла, его можно заменить на любое возможное (учитывая правила имён переменных), для этого используется as:

@use "./module" as fn;

.card {
    color: fn.$redcolor;
    @include fn.flex-wrapper;
}

Мы можем отменить пространство имён указав в качестве нового имени *. Тогда вызов переменных/миксинов будет стандартный, как при использовании @import. Но такое использование рекомендуется только для файлов с миксинами, переменными, функциями без переменных и маленьких проектов. В ином случае есть риск конфликта имен и глобального загрязнения. 

@use "./module" as *;

.card {
    color: $redcolor;
    @include flex-wrapper;
}

@forward

@forward - директива, которая передает содержимое одного файла дальше для использования в других файлах.

Например, у нас есть отдельный файл с миксинами _mixins.scss и один с переменными _variables.scss. Мы можем по одиночке импортировать каждый из этих файлов в наш main.scss с помощью @use, либо создать единый файл (хаб), где будут храниться все необходимые нам модули, и импортировать в main.scss только его одного.

Важное уточнение: @use используется только локально в одном конкретном файле, и не может быть посредником в хабе, тогда как @forward предназанчен именно для этого.

_index.scss файл сборник (хаб)

@forward "mixins";
@forward "variables";

main.scss (основной рабочий файл)

@use "index" as *;

Добавление префикса

@forward 'mixins' as lib-*; - добавляем любой префикс к импортируемым данным. Данные будут работать только с префиксом

Полезно для предотвращения конфликтов имён, указывает откуда пришли данные.

_index.scss файл сборник (хаб)

@forward "mixins as index-*";
@forward "variables";

@use "index" as *;

\\импортирумый миксин с именем grid-wrapper
.test {
    @include index-grid-wrapper;
}

Видимость данных

@forward 'variables' hide $private-var, $temp; - скрываем указанные переменные\миксины\функции. Данные переменные переноситься не будут.

@forward 'functions' show calculate, map-get-rem; - передаёт только указанные миксины и функции (с переменными не работает).

Комбинации

@forward 'mixins' as lib-* hide lib-private, lib-temp; - можно комбинировать перфиксы и видимость, но нельзя сочетать одновременно hide и show.

Изменение переменных

При необходимости значение переменных можно изменить в хаб-файле. И передать уже измененые значения дальше.

Для этого в экспортируемом файле у переменных, которые желаем изменить ставим !default

файл для экспорта

$redcolor: #e21111 !default;
$main__width: 1440px !default;

@mixin main-theme {
    display: flex;
    border-color: $redcolor;
    max-width: $main__width;
}

В хаб-файле вызываем @use указывая путь к файлу, и спец слово with. В круглых скобках через запятую указываем наши переменные с измененными значениями. В конце отправляем файл на экспорт через @forward

Хаб-файл

@use "variables" with (
    $redcolor: blue,
    $main__width: 800px
);

@forward "variables";

В основном файле, используя переданные переменные их значения будут новыми, также значения поменяются и у миксинов, если те ссылаются на переданные переменные.
