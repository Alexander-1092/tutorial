SCSS

SASS это препроцессор CSS, то есть инструмент, который позволяет писать CSS с расширенным синтаксисом, после чего компилирует его в обычный CSS.

Есть две версии SASS, оригинальная, которая так и называестя SASS и современная SCSS. Разница между ними заключается в синтаксисе.

Вложенность

Структура SCSS визуально схожа с html, но вместо тегов указываются CSS селекторы.

<nav class="nav">
    <ul>
        <li>
            <a class="link"></a>
        </li>
    </ul>
</nav>

.nav{
    ul{
        li{
         .link{}
        }
    }
}

При этом вложенность не должна обязательно быть строгой, вплоть до каждого селектора.

.nav{
    margin-top: 20px;
    .link{color: red;}
}

Однако хорошей практикой считается отзеркаливанием html структуры, но это неформальное соглашение, а не правило. При этом стоит избегать избыточности.

Переменные

Чтобы создать переменную нужно использовать символ $.

$primary-color: #333;

Значение переменной может быть цвета, стеки шрифтов или любые другие значения CSS

Для того чтобы использовать созданную переменную, нам нужно указать ее название через символ $ 

button {
    color: $primary-color;
}

Оператор &

Оператор & — это ссылка на родительский селектор, то есть он копирует название родителя.

<div class="parent">
    <div class="parent__title"></div>
    <div class="parent__text"></div>
</div>

.parent {
    &__title {
        color: blue;
    }

    &__text {
        color: red;
    }
}

Псевдоклассы и селекторы

Селекторы

SCSS поддерживает все CSS-селекторы и псевдоклассы.

  • Пробел - потомок .parent .child. Любой ребенок внутри родителя.
  • > - дочерний .parent > .child.Потомок первого уровня.
  • + - соседний элемент .child + .text.Следующий соседний элемент.
  • ~ - родственный.child ~ p.Все следующие соседние элементы.

Псевдоклассы

nth-child

  &:nth-child(1) { }       // первый
  &:nth-child(3n+1) { }    // каждый третий начиная с первого
  &:nth-last-child(2) { }  // второй с конца
  &:nth-child(odd) { }     // нечетные
  &:nth-child(2n) { }     // четные
  &:nth-child(even){ }    // четные

nth-of-type

p {
  &:nth-of-type(3) { }    // третий элемент указанного типа (p)
  &:nth-last-of-type(2) { } //Второй с конца среди p элементов
}

Другие структурные

p {
.item {
  &:first-child { } //  Выбираем первый элемент родителя
  &:last-child { }  // Последний элемент родителя
  &:only-child { }  // Элемент только с одним ребенком
  &:empty { }       // выбираем пустой элемент
}
}

#{} интерполяция

Интерполяция - это способ вставки значений переменных непосредственно в селекторы, имена свойств, строки, медиа-выражения.

$base: "header";
$side: "left";

.#{$base} {
    width: 100px;
    margin-#{$side}: 20px;
}
В CSS

.header {
  width: 100px;
  margin-left: 20px;
}

Миксины

Миксины - это группа CSS свойств. По своей сути эта переменная, только вместо одного значения, миксин содержит группу разных свойств.

@mixin - для создание миксина.

@include - для использования миксина.

@mixin flex-center {
    display: flex;
    justify-content: space-between;
    align-items: center;
}
container {
   @include flex-center;
}

Аргументы в миксине

В миксине можно передавать значение для свойства через аргумент. Это полезно если у вас одиноковые фрагменты кода, но разные значения свойств.

@mixin box($width, $height, $color: blue) {
  width: $width;
  height: $height;
  background-color: $color;
}

.header {
  @include box(100%, 200px, red);
}

Произвольное количество аргументов

Когда нам нужно передать большой массив значений, и затруднительно прописывать каждый аргумент.

@mixin shadows($shadows...) {
  box-shadow: $shadows;
}

.card {
  @include shadows(0 2px 5px rgba(0,0,0,0.1), 0 0 0 1px #eee);
}

@content

@content - это инструмент, который работает внутри миксина, и позволяет вставить на его место любой фрагмент когда, в том числе вложенные селекторы, медиа-запросы, даже другие миксины. Данное свойство нужно использовать тогда когда мы сами точно не знаем какие свойства будут использованны внутри.

Например:

@mixin tablet {
  @media (min-width: 768px) and (max-width: 1023px) {
    @content;  // Что тут будет? Неизвестно!
  }
}

Вариант 1

.sidebar {
  width: 300px;

  @include tablet {
    width: 100%;
    background: lightblue;
  }
}

Вариант 2

.gallery {
  display: grid;
  grid-template-columns: repeat(4, 1fr);

  @include tablet {
    grid-template-columns: repeat(2, 1fr);
    gap: 10px;
  }
}

Используются абсолютно разные свойства и значения.

@extend (наследование)

@extend -это механизм, который позволяет одному селектору получить все стили другого (или нескольких других) селекторов, без копирования кода. При этом их иерархия, где находится копируемый селектор (до или после) не важно. Но важно понимать, что в отличие от миксинов @extend не копирует код, а группирует селекторы, так чтобы они наследовали свойства.

В SCSS
 .card {
    @extend .box;
    justify-content: space-between;
}

.box {
    display: flex;
    flex-direction: column;
}

В CSS
.card {
  justify-content: center;
}

.box, .card {
  display: flex;
  flex-direction: column;
}

Placeholder-селектор %

Placeholder-селектор % - работает аналогично @extend только класс к которому применен селектор не компилируется в CSS. Получается шаблон, который существует только для наследования. Таким образом, мы избегаем "мусорных" классов. 

%box {
    display: flex;
    flex-direction: column;
}

 .card {
    @extend %box;
    justify-content: space-between;
}

Импорт в SCSS

Статья - источник

Раньше для импорта данных в SCSS применялся @import, сейчас же он считается устаревшим, и будет удален. На замену ему пришли @use и @forward

@use

@use - загружает файл (модуль) и делает его содержимое доступным в текущем файле, но в изолированном пространстве имен (переменные/миксины не будут доступны при стандартном вызове), чего не было у @import.

Использование: указываем в кавычках путь к файлу, можно без расширение, если модуль находится в папке с главным SCSS файлом, то можно просто название файла в кавычках.

При импорте обычные селекторы будут сразу применены. Для использования миксинов или переменных вначале нужно указать пространство имён, то есть имя файла, а зачем имя переменной/миксина.

module.scss

$redcolor: #e21111;

@mixin flex-wrapper {
    display: flex;
    flex-direction: column;
}

.card {
    width: 500px;
}


@use "./module";

.card {
    color: module.$redcolor;
    @include module.flex-wrapper;
}

Изменение пространства имён (as)

При импорте, мы указываем имя файла, его можно заменить на любое возможное (учитывая правила имён переменных), для этого используется as:

@use "./module" as fn;

.card {
    color: fn.$redcolor;
    @include fn.flex-wrapper;
}

Мы можем отменить пространство имён указав в качестве нового имени *. Тогда вызов переменных/миксинов будет стандартный, как при использовании @import. Но такое использование рекомендуется только для файлов с миксинами, переменными, функциями без переменных и маленьких проектов. В ином случае есть риск конфликта имен и глобального загрязнения. 

@use "./module" as *;

.card {
    color: $redcolor;
    @include flex-wrapper;
}

@forward

@forward - директива, которая передает содержимое одного файла дальше для использования в других файлах.

Например, у нас есть отдельный файл с миксинами _mixins.scss и один с переменными _variables.scss. Мы можем по одиночке импортировать каждый из этих файлов в наш main.scss с помощью @use, либо создать единый файл (хаб), где будут храниться все необходимые нам модули, и импортировать в main.scss только его одного.

Важное уточнение: @use используется только локально в одном конкретном файле, и не может быть посредником в хабе, тогда как @forward предназанчен именно для этого.

_index.scss файл сборник (хаб)

@forward "mixins";
@forward "variables";

main.scss (основной рабочий файл)

@use "index" as *;

Добавление префикса

@forward 'mixins' as lib-*; - добавляем любой префикс к импортируемым данным. Данные будут работать только с префиксом

Полезно для предотвращения конфликтов имён, указывает откуда пришли данные.

_index.scss файл сборник (хаб)

@forward "mixins as index-*";
@forward "variables";

@use "index" as *;

\\импортирумый миксин с именем grid-wrapper
.test {
    @include index-grid-wrapper;
}

Видимость данных

@forward 'variables' hide $private-var, $temp; - скрываем указанные переменные\миксины\функции. Данные переменные переноситься не будут.

@forward 'functions' show calculate, map-get-rem; - передаёт только указанные миксины и функции (с переменными не работает).

Комбинации

@forward 'mixins' as lib-* hide lib-private, lib-temp; - можно комбинировать перфиксы и видимость, но нельзя сочетать одновременно hide и show.

Изменение переменных

При необходимости значение переменных можно изменить в хаб-файле. И передать уже измененые значения дальше.

Для этого в экспортируемом файле у переменных, которые желаем изменить ставим !default

файл для экспорта

$redcolor: #e21111 !default;
$main__width: 1440px !default;

@mixin main-theme {
    display: flex;
    border-color: $redcolor;
    max-width: $main__width;
}

В хаб-файле вызываем @use указывая путь к файлу, и спец слово with. В круглых скобках через запятую указываем наши переменные с измененными значениями. В конце отправляем файл на экспорт через @forward

Хаб-файл

@use "variables" with (
    $redcolor: blue,
    $main__width: 800px
);

@forward "variables";

В основном файле, используя переданные переменные их значения будут новыми, также значения поменяются и у миксинов, если те ссылаются на переданные переменные.

Арифметические операции

Сложение и вычитание. Складывать\вычитать можно только совместимые данные, один тип единиц с таким же типом единиц, например 10px + 20px.

SCSS умеет преобразовывать единицы если у одного из членов выражения указан тип единицы, например 10px - 5

Умножение. Умножать можно только единицу с числом, то есть можно: padding: 20px * 2, а не padding: 20px * 2px;. В первом случае выражение в CSS сразу преобразуется в 40px, тогда как во втором это будет выглядеть так: calc(40px * 1px).

Хотя в данном примере, и первый и второй случай результатом будет 40px. Но при втором варианте страдает производительность, браузеру приходится разбирать выражение, обнаружить нестандуртную единицу, привести к стандартному виду, и потом вычислять результат.

Проблема совместимости со старыми браузерами, подобное выражение - calc(40px * 1px), может быть просто проигнорированна.

Относительные единицы. При умножение относительных единиц друг на друга результат может быть непредсказуем из-за неверного рассчета контекста.

Деление. Для деления выражение необходимо оборачивать в круглые скобки, так как символ слэша уже зарезерирован в системе:padding: (20px / 2);.

При делении мы можем указывать у делителя единицу измерения padding: (20px / 2px);. Однако в таком случа, результатом будет не 10px, а просто 10. Это можно использовать там где нам нужно просто число.

Проценты. Для вычисления процентов необходимо использовать функцию calc() padding: calc(100px - 20%).

Остаток. используется оператор % без скобок: padding: 100px % 3;. Возможно использовать единицы измерения padding: 100px % 3px;, но они должны совпадать. При этом такая запись менее гибкая, избыточна и высок риск ошибки.

функция if, директива @if

функция if

Функция if возвращает одно из двух указанных значений. Имеется два синтаксиса оформления: старый и новый.

Старый: padding: if($size > 10px, 20px, 10px); Всё еще рабочий, но в будущем будем удален.

Если переменная $size больше 10px, то вернет 20px, если меньше, то 10px.

Новый: padding: if(sass($size > 10): 20px; else: 10px);

Директива @if

В отличие от функции директива @if не возвращает значение, а генерирует CSS код, и работает как обычный if в js.

Директива @if может использоваться как одиночно:

$theme: 'dark';

.button {
  @if $theme == 'dark' {
    background: #1a1a1a;
    color: #ffffff;
  }
}

Так и совместно с директивами @else if и @else:

$size: large;

.button {
  @if $size == large {
    padding: 12px 24px;
    font-size: 18px;
  } @else if $size == medium {
    padding: 8px 16px;
    font-size: 16px;
  } @else {
    padding: 4px 8px;
    font-size: 14px;
  }
}

Операторы сравнения

Доступны следующие операторы сравнения:

== (равно), != (неравно), >(больше), < (меньше), >= (больше или равно), <= (меньше или равно)

@mixin spacing($padding, $margin) {
        @if ($padding > $margin) {
            padding: $padding;
        } @else {
            margin: $margin;
        }
}

.container {
   @include spacing(10px, 20px);
}

Логические операторы

SCSS поддерживает три логических оператора для создания сложных условий в директивах @if, @else if, а также в функции if(): and (и), or (или), not (не). Работают также как операторы &, ||, ! в js. 

$width: 100px;
$height: 200px;

.element {
  @if $width > 50px and $width < 150px {
    background: green;
  }
}

Строки

Есть два типа строк: c кавычками и без/

content: "Hello world"; и display: flex;

Как в js строки можно складывать используя оператор +

.test::after {
    content: "Hello " + "world";
    display: fl + ex;
}

Директива @for

Директива @for выводит набор стилей заданное число раз.

Синтаксиси @for $переменная from начало through конец {}

$i - переменная-счетчик, ее можно указывать для изменения селектора.

from - указывает начало отсчета.

through - до какого отсчитываем.

.test {
    @for $i from 1 through 3 {
        .child-#{$i} {
            width: 10px * $i;
        }
    }
}

CSS

.test .child-1 {
  width: 10px;
}
.test .child-2 {
  width: 20px;
}
.test .child-3 {
  width: 30px;
}

Можно использовать как внутри селектора, так и вне его. Если используем снаружжи, то генерируются независимые, отдельные классы, если внутри, то у них появляется родититель. .

Директива @each

@each - это цикл для перебора элементов списка или карты (map).

Синтаксиси - @each $item in $список {$item}

$sizes: 10px, 20px, 30px;

@each $size in $sizes {
    .test-#{$size} {
        margin-top: $size;
    }
}

CSS

.test-10px {
  margin-top: 10px;
}

.test-20px {
  margin-top: 20px;
}

.test-30px {
  margin-top: 30px;
}

Директив @while

Директива @while создаёт циклы, которые выполняются до тех пор, пока указанное условие истинно.

Синтаксис@while условие {}

$i: 1;

@while $i <= 3 {
    .item-#{$i} {
        width: 20px * $i;
    }
    $i: $i + 1; // Важно: увеличиваем счётчик!
}

CSS

.item-1 {
  width: 20px;
}

.item-2 {
  width: 40px;
}

.item-3 {
  width: 60px;
}argin-top: 30px;

Директива @function

Директива @function создает функции.

Синтаксис @function имя($параметры) {@return значение;}. 

@function connect($str1, $str2) {
    @return $str1 + " " + $str2;
}

.test::after {
    content: connect("Hello", "World");
}

CSS

.test::after {
  content: "Hello World";
}

Можно задавать и более сложные условия:

@function theme($color) {
    @if ($color == "dark") {
        @return black;
    } @else if($color == "white") {
        @return white;
    } @else {
        @return red;
    }
}

.test {
    background-color: theme("white");
}

CSS

.test {
  background-color: white;
}

Директивы @debug @warn и @error

Директивы @debug, @warn и @error в SCSS используются для отладки и контроля ошибок во время компиляции. Они не влияют на итоговый CSS.

@debug

Выводит отладочное сообщение в консоль. Компиляция продолжается.

Используется когда нужно быстро проверить значение переменной, результат функции или математического выражения.

Требует настройки, если ручная компиляция sass style.scss style.css, то нужно добавить флаг --trace или --verbose - sass style.scss style.css --trace. Если используется Live Sass Compiler, то в палитре команд вводим Live Sass: Show Output On Debug.

Если используем сборщик ('Webpack'), то в конфигурациях находим sass-loader и в sassOptions: прописываем значение verbose: true

@function theme($color) {
    @if ($color == "dark") {
        @return black;
    } @else if($color == "white") {
        @return white;
    } @else {
        @return red;
    }
}

@debug theme("dark");

output

Debug info:
black
   ╷
70 |@debug theme("dark");
   |^....................^
   ╵

@warn

Выводит предупреждение в консоль. Компиляция продолжается, но вы видите, что код делает что-то нежелательное.

Используется чтобы сообщить другому разработчику, что данный фрагмент кода лучше заменить. 

@function theme($color) {
    @if ($color == "dark") {
        @return black;
    } @else if($color == "white") {
        @return white;
    } @else {
        @return red;
    }
}

@debug theme("dark");

output

Warning:
black

@error

Полностью останавливает компиляцию и выбрасывает фатальную ошибку. CSS-файл сгенерирован не будет.

Используется если входные данные неверны (например, цвет передан черный, а нужно светлый), или нарушено ключевое условие работы функции.

Модули

В SCSS есть множество встроеных функций, есть устаревшие глобальные функции, для которого не требуется импорт, и новые, для которых импорт модуля обязателен.

color

Для использования любого модуля, вначале следует его импортировать - @use "sass:color";

color.adjust($color, $lightness: 10%) - Увеличивает или уменьшает конкретный параметр цвета на фиксированную величину. Может изменять lightness (светлость), saturation (насыщенность), red, green, blue и другие.

color.scale(#333, $lightness: 50%); - Изменяет параметр цвета пропорционально от текущего значения к пределу.

color.mix(red, blue, 70%); - Смешивает два цвета. Третий параметр — вес первого цвета в процентах (по умолчанию 50%).

@use "sass:color";

.test {
  color: color.adjust(red, $lightness: 10%);
  border-color: color.scale(#333, $lightness: 50%);
  background: color.mix(red, blue, 70%);
}


CSS

.test {
  color: #ff3333;
  border-color: #999999;
  background: rgb(178.5, 0, 76.5);
}

string

@use "sass:string"; - модуль для импорта.

string.quote(Helvetica); - оборачивает в кавычки.

string.unquote("Helvetica");; - возвращает без кавычек.

string.index("Hello", "l"); - ищет позицию первого вхождения.

string.insert("Hello world!", " wonderful", 6); - делает вставку по указанному индексу.

string.slice($string, $start-at, $end-at: -1) - вырезает строку по указанным позициям (не индексу).

string.length($string) - возвращает количество символов в строке.

string.split($string, $separator, $limit: null) - разбивает строку на список по сепаратору. Параметр limit необязателен, служит для ограничения возвращаемых элементов.

string.to-lower-case($string) - возвращает строку в нижнем регистре.

string.to-upper-case($string) - возвращает строку в верхнем регистре.

string.unique-id() - создает случайный идентификатор.

@use "sass:string";

.test::after {
    $word: string.quote(hello);
    $x: string.index($word, "l");
    content: string.slice($word, 2, $end-at: 4) + " " + $x;
}

CSS

.test::after {
  content: "ell 3";
}

math

@use "sass:math"; - модуль для импорта.

math.ceil(4.2); - округление верх.

math.floor(4.8) - округляем вниз.

math.random(); - возвращает случайное число от 0 до 1 .

math.random(10) - возвращает случайное число от 1 до 10.

math.max(20px, 100px, 50px); - возвращает наибольшее значение.

math.min(20px, 100px, 50px); - возвращает наименьшее значение.

math.percentage($number) - преобразует в проценты.

Также в модуле имеются тригонометрические (синус, косинус, тангенс....), экспоненциальные (степени, логарифмы, корни) и некоторые другие функции.

@use "sass:math";

.test {
    width: math.ceil(4.2) + px;
    height: math.floor(4.8) + px;
    max-width: math.random() + px;
    min-width: math.random(10) + px;
    min-height: math.max(20px, 100px, 50px);
    max-height: math.min(20px, 100px, 50px);
}


CSS

.test {
  width: 5px;
  height: 4px;
  max-width: 0.4064989611px;
  min-width: 9px;
  min-height: 100px;
  max-height: 20px;
}

list

@use "sass:list"; - модуль для импорта.

list.append(['foo', 'bar'], 'baz'); -добавляет элемент в конец списка.

list.index($list, $value); - поиск индекса элемента по значению.

list.nth($list, $n); - возвращает элемент списка по индексу.

list.join($list1, $list2); - объединяет два списка в один.

list.length($list) - возвращает количество элементов в списке.

@use "sass:list";

$colors: red, green, blue;
$newColors: list.append($colors, yellow);
$indexColor: list.nth($newColors, 4);
$length: list.length($newColors);
.test {
    color: $indexColor;
    width: $length;
}



CSS

.test {
  color: yellow;
  width: 4;
}

map (объекты)

@use "sass:map"; - модуль для импорта.

map.get($map, $key) - возвращает значение по ключу.

map.set($map, $key, $value) - создаёт новый мап с измененным значением конкретного ключа.

map.merge($map1, $map2) - объединяет два мапа в один. Если ключи совпадают, то ключ первого переписывается.

map.keys($map) - возвращает список всех ключей.

map.has-key($map, $key) - проверяет, существует ли ключ в мапе. Возвращает true или false..

@use "sass:map";

$default: (
    "color": black,
    "size": 16px,
    "weight": normal
);

$custom: (
    "color": blue,
    "weight": bold
);

$merged: map.merge($default, $custom);

.test::after {
    color: map.get($merged, "color");
    content: map.keys($merged);
    @if (map.has-key($merged, "weight")) {
        font-weight: map.get($merged, "weight");
    } @else {
        font-weight: map.get($merged, "normal");
    }
}

CSS

.test::after {
  color: blue;
  content: "color", "size", "weight";
  font-weight: bold;
}

meta

@use "sass:meta"; - модуль для импорта.

Применяется для получения информации о коде во время компиляции.

meta.type-of($value); - определить тип данных.

$value: 42;
@debug meta.type-of($value);//number

meta.global-variable-exists($name); - проверка глобальных переменных. Имя переменной указываем без $

$value: 42;
@debug meta.global-variable-exists(value);\\ true

Аналогично работают: meta.function-exists($name); - проверяет существование функции, и meta.mixin-exists($name); - проверяет существовании миксина.

meta.module-functions($module); - показывает все встроенные функции указанного модуля. Модуль должен быть импортирован.

@debug meta.module-functions(map);
\\Debug info:
("get": get-function("get"), "set": get-function("set"),
"merge": get-function("merge"),.....)
